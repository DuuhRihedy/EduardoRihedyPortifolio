## 🎯 Sobre o Projeto

O portfólio de **Eduardo Rihedy Dorneles** foi construído sem o uso de frameworks pesados de frontend para demonstrar domínio completo sobre os fundamentos da Web (DOM, CSS Flexbox/Grid, eventos nativos em JavaScript e semântica de HTML).

---

## ✨ Funcionalidades Principais

- 📱 **Layout Totalmente Responsivo:** Design adaptado para telas mobile, tablets e monitores ultrawide.
- 🌐 **Sistema de Internacionalização (i18n):** Alternância de idioma entre Português (PT-BR) e Inglês (EN) através de atributos de dados (`data-i18n`) e JavaScript puro.
- 🎨 **Interações & Animações Nativas:** Menu de navegação móbile com toggle, scroll suave e destaque de seções ativas.
- 🚀 **Performance Máxima:** Carregamento ultra-rápido sem pacotes de terceiros no bundle.

---

## 🛠️ Tecnologias Utilizadas

- **Estrutura & Estilo:** HTML5 Semântico, CSS3 (Variáveis CSS, Flexbox, Grid Layout)
- **Lógica:** Vanilla JavaScript (ES6+)
- **Ícones:** BoxIcons
- **Hospedagem:** GitHub Pages (`.nojekyll`)

---

## 🚀 Como Executar Localmente

Não requer instalação de Node.js ou gerenciadores de pacotes.

```bash
# 1. Clone o repositório
git clone https://github.com/DuuhRihedy/EduardoRihedyPortifolio.git
cd EduardoRihedyPortifolio

# 2. Abra o arquivo index.html no seu navegador preferido ou utilize o Live Server do VSCode.
```
