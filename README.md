## 🚀 Features

- ✅ **Design Responsivo:** Adaptado perfeitamente para Desktop, Tablet e Mobile.
- ✅ **Vanilla JS:** Interações (Scroll, Menu Toggle) feitas puramente em JavaScript, garantindo carregamento instantâneo.
- ✅ **SEO Otimizado:** Metatags, Open Graph e estrutura semântica aplicados.
- ✅ **Multi-idioma:** Sistema simples de internacionalização (i18n) via atributos de dados.
- ✅ **Deploy Estático:** Hospedado via GitHub Pages (`.nojekyll`).

## ⚡ Quick Start

### Instalação

Como é um projeto puramente estático (Vanilla), você não precisa do Node.js.

1. Clone o repositório
```bash
git clone https://github.com/DuuhRihedy/EduardoRihedyPortifolio.git
cd EduardoRihedyPortifolio
```

2. Execute localmente
Basta abrir o arquivo `index.html` em qualquer navegador, ou rodar com o Live Server do VSCode.

## ⚙️ Deploy

O projeto está hospedado no GitHub Pages. Para atualizá-lo, basta fazer o push das alterações para a branch `main`.
